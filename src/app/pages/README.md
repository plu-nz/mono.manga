# Screens

- `LibraryPage.tsx`: saved titles, favorites, and new chapters.
- `SearchPage.tsx`: MangaDex search and file import.
- `MangaPage.tsx`: title details, chapter list, selection for offline saving and Kindle.
- `ReaderPage.tsx`: paged (right-to-left or left-to-right) and vertical reader with progress saving.
- `DownloadsPage.tsx`: offline chapters and storage use.
- `SettingsPage.tsx`: language, reader, Kindle, Google account, storage, and about.

See the [app index](../README.md).
