# Public assets

Served as-is from the site root.

- `favicon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`: app icons (manga panels in PLUNZ orange and blue). PNGs are rendered from the SVG with `rsvg-convert`.
- `privacy.html`: privacy policy, linked from Settings and required for Google OAuth verification.

See the [repository README](../README.md).
